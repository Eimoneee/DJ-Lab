# Artist Taxonomy System

A structured system for classifying artists by broad sonic tendencies. This helps you compare production styles, understand what makes each artist distinctive, and find similar artists for your sets.

## Taxonomy Dimensions (1–5 Scale)

| Dimension | Description | 1 (Low) | 5 (High) |
|---|---|---|---|
| **Groove** | Swing, shuffle, rhythmic feel | Straight / rigid | Heavy swing / shuffle |
| **Percussion Density** | How layered the percussion is | Sparse / minimal | Dense / complex |
| **Low-End** | Sub bass weight and kick character | Light / thin | Heavy / dominant |
| **Arrangement** | Song structure and progression | Minimal / repetitive | Complex / dynamic |
| **Tension Style** | How tension and release work | Subtle / gradual | Dramatic / intense |
| **Vocal Usage** | How vocals are used | None / rare | Prominent / central |
| **Energy Profile** | Overall intensity level | Deep / hypnotic | Peak-time / high-energy |

## How to Use This Taxonomy

1. **Compare artists** before building a set — find artists with similar energy profiles but different groove styles for interesting transitions
2. **Identify gaps** in your library — if all your artists score high on energy, you might need more deep/hypnotic options
3. **Study patterns** — artists who score high on groove but low on tension create dance floor flow; artists with high tension create peak moments
4. **Build set arcs** — sequence artists from low energy → high energy, or find artists that share groove styles for seamless mixing
