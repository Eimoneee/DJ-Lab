# DJ Lab — Curriculum Map

## Overview

A structured, progressive learning path for house and tech house DJing and production. Each phase builds on the previous one. Lessons are short and practical.

Every lesson includes:
- **Title** — what you're learning
- **Objective** — what you'll be able to do after
- **Explanation** — the concept or technique
- **Exercise** — hands-on practice task
- **Common Mistakes** — pitfalls to avoid
- **Success Checklist** — how to know you've got it

---

| # | Lesson | Key Skill |

## Progression Logic

- Phases unlock sequentially: complete 80%+ of a phase to unlock the next
- Within a phase, lessons are ordered but can be done in any order
- Exercises must be attempted (not necessarily perfected) to mark a lesson complete
- The dashboard shows: current lesson, completed count, and next suggested lesson
- Practice logging is encouraged alongside all phases
